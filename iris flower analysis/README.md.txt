# Iris Flower Analysis

## Overview

This project analyzes the Iris Flower dataset using Python and data visualization techniques.

## Skills Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Exploratory Data Analysis (EDA)

## Analysis Performed

* Dataset inspection
* Species distribution analysis
* Scatter plot visualization
* Correlation heatmap
* Pairplot analysis

## Key Findings

* Setosa is clearly separable from the other species.
* Petal measurements are highly useful for classification.
* Strong correlation exists between petal length and petal width.
