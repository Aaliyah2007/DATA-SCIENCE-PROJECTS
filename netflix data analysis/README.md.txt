# Netflix Data Analysis

## Overview

This project analyzes Netflix content using Python, Pandas, and data visualization techniques.

## Skills Used

* Python
* Pandas
* Matplotlib
* Exploratory Data Analysis (EDA)

## Analysis Performed

* Dataset inspection
* Missing value analysis
* Movies vs TV Shows distribution
* Release year trend analysis
* Country-wise content analysis
* Genre analysis

## Key Findings

* Movies are more common than TV Shows on Netflix.
* Netflix content production increased significantly in recent years.
* A few countries contribute a large portion of Netflix content.
* Certain genres dominate Netflix's catalog.
